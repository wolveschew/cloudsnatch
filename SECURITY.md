# Security

## Supported versions

Security fixes are applied to the latest release. Download installers and APKs only from this repository's Releases page.

## Reporting a vulnerability

Please report vulnerabilities privately using GitHub's **Security → Advisories → Report a vulnerability** feature for this repository. Do not include passwords, private account data, or other sensitive material in a public issue.

CloudSnatch does not accept SoundCloud credentials or browser cookies. Its intended scope is public collection metadata only. The Android release signing key must remain in protected GitHub Actions secrets and must never be committed.
